# Hardware

Default: **virtual** (desktop DMD window and MPF Monitor, `game/config/hw_virtual.yaml`), since no machine was
named. The VPX table simulates the Pro, so the VPX bridge (agent D) uses the same config.

Real machine on a P-ROC on the SAM boards: `game/config/rom/proc_numbers.yaml` holds every switch, coil and lamp
as libpinproc's `sternSAM` numbers (generated by scripts/gen_config.py; dedicated switches D1-D24 as SDn, coils
33-35 are aux outputs and stay virtual). Not tried on a machine yet; coil times are MPF defaults until the ROM
extraction decodes them, so check coil strengths before playing.
